Ferrowl은 사용자를 추적하지 않는 iPhone용 메일 앱입니다. 모든 IMAP 또는 POP3 메일함(Gmail, Outlook, iCloud, 회사 메일 서비스 또는 직접 운영하는 서버)에서 작동하며, 메시지는 오직 사용자의 iPhone만 내려받습니다. 광고도, 프로파일링도 없는 오픈 소스 앱입니다.

엿보는 사람 없이 읽기
• JavaScript 없이 깔끔하게 표시되는 HTML 메시지
• 원격 이미지를 끌 수 있어 보낸 사람이 메시지를 연 시점을 알 수 없음
• OpenPGP 서명 및 암호화, 서명되거나 암호화된 메시지를 명확하게 표시
• 발신자와 도메인 전체를 차단하거나 허용

더 빠르게 처리
• 보관, 이동, 스팸 신고, 삭제를 순식간에, 실행 취소는 탭 한 번으로
• 이미 내려받은 모든 메일 검색, 오프라인에서도 가능
• 받은 메시지에 대한 자동 규칙
• 새 메일 즉시 알림
• 위젯, 단축어, iPhone 검색

모든 것을 한곳에서
• 하나의 앱에서 여러 메일함 사용, 메일함별 읽지 않은 메일 수 표시
• 캘린더와 연락처(CalDAV 및 CardDAV), 초대는 메시지에서 바로 회신
• 첨부파일, 참조, 숨은참조를 포함한 메일 작성
• 6가지 색상 테마와 10개 언어

개인정보 보호 우선
광고도, 추적도, 데이터 판매도 없습니다. 암호와 키는 iPhone의 키체인에 보관됩니다. 즉시 알림을 켜면 Ferrowl 서버가 메일함을 확인하고 휴대폰에는 신호만 보냅니다. 계정 설정은 iPhone 밖으로 나가지 않는 키로 암호화된 상태로 유지됩니다. Ferrowl은 오픈 소스입니다. 코드는 공개되어 있으며 누구나 검증할 수 있습니다.
